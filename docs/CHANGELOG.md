# Histórico de mudanças

Este arquivo resume mudanças que afetam o projeto. Os pacotes prontos para jogar e as instruções específicas de cada versão ficam nos [GitHub Releases](https://github.com/vinicius589/soldados-vs-zumbis/releases).

## Em desenvolvimento

- Importação seletiva da base jogável da Beta 4 para este repositório.
- Separação entre o ponto de entrada e a implementação legada do runtime.
- Documentação simplificada e processo de CI, compilação e publicação reconstruído.
- Material bruto e ferramentas de produção deixados no repositório histórico, fora da linha principal.

A reorganização não muda, por si só, as mecânicas do jogo. Funcionalidades novas só devem ser listadas quando forem implementadas e testadas.
